# Sonar

SmartRadar'ın ikinci sürümü (eski adı FinRadar Alternate): altı Borsa İstanbul şirketinin finansalları, boşluklar KAP ve şirket raporlarından tamamlanmış, her hücrenin kaynağı görünür.

- Statik site: `index.html` (veri sayfaya gömülü)
- Render: `render.yaml` → servis adı sonar (şimdilik https://finradar-x849.onrender.com)
- Marka varlıkları: `marka/` (logo, ikon, favicon, profil ve paylaşım görselleri)
